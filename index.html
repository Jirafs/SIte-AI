1. Пояснительная записка

1.1. Актуальность

Современный образовательный процесс в системе среднего профессионального образования требует внедрения инструментов, позволяющих интенсифицировать формирующую обратную связь — оперативную, персонализированную и конструктивную помощь студенту в процессе выполнения практических заданий. Традиционная модель проверки работ преподавателем не всегда обеспечивает своевременность и индивидуализацию обратной связи, что снижает эффективность обучения.

Генеративные нейросети (ChatGPT, YandexGPT, GigaChat и др.) открывают новые возможности для организации самопроверки и самокоррекции студентов, выступая в роли предикторов типовых ошибок и навигаторов коррекции, направляющих студента к правильному решению с помощью наводящих вопросов, а не предоставления готовых ответов.

1.2. Цель рекомендаций

Повышение качества выполнения практических заданий по дисциплине ОП.03 «Информационные технологии» за счёт внедрения ИИ-навигаторов коррекции в структуру практических занятий, обеспечивающих оперативную формирующую обратную связь и развитие навыков самооценки у студентов.

1.3. Задачи

  • Интегрировать ИИ-инструменты в структуру практических занятий на этапе самопроверки.
  • Разработать систему промптов (запросов) для разных типов заданий.
  • Сформировать у студентов навыки критической оценки результатов работы ИИ.
  • Снизить рутинную нагрузку на преподавателя по проверке однотипных заданий.
  • Повысить мотивацию и вовлечённость студентов в процесс обучения.

2. Памятка для студентов «Как эффективно работать с ИИ-навигатором коррекции»

  1. Используй ИИ для самопроверки, а не для получения готового ответа. Твоя задача — научиться видеть и исправлять ошибки, а не перекладывать работу на нейросеть.
  2. Внимательно анализируй подсказки. ИИ может ошибаться. Проверяй, насколько адекватны его рекомендации.
  3. Сохраняй первоначальный вариант работы. Это поможет тебе увидеть прогресс и проанализировать свои типичные ошибки.
  4. Не копируй ответы ИИ. Все исправления вноси самостоятельно, используя подсказки как направление для размышления.
  5. Учись формулировать вопросы. Чем точнее твой запрос к ИИ, тем полезнее будет обратная связь.
  6. Участвуй в рефлексии. Обсуждай с преподавателем и одногруппниками свой опыт работы с ИИ — это поможет закрепить навыки.
  7. Помни об академической честности. ИИ — это инструмент для обучения, а не способ обойти требования задания.

2.1. Алгоритм работы с промптом (пошаговая инструкция)

  1. Выполните задание полностью.
  2. Откройте методичку и найдите промпт для вашего задания.
  3. Скопируйте промпт целиком.
  4. Вставьте промпт в чат с ИИ.
  5. Вместе с промптом добавьте ТЗ и ваш файл с выполненным заданием.
  6. Получите ответ в виде списка из 3–5 пунктов.
  7. Для каждого пункта:
    • Прочитайте проблему.
    • Прочитайте наводящий вопрос.
    • Найдите ответ самостоятельно.
    • Исправьте работу.
  8. Если проблема осталась — задайте уточняющий вопрос (но не просите готовое решение) или обратитесь за помощью к преподавателю.
  9. Повторяйте, пока все пункты не будут закрыты.
