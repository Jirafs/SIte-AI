# Интерактивная методичка ОП.03 «Информационные технологии» (09.02.07)

Сайт-методичка с ИИ-навигатором, который работает прямо в браузере.

## Два способа пользоваться

### 1. Локально (рекомендуется - полностью бесплатно и стабильно)

1. Скопировать папку на компьютер.
2. Дважды щёлкнуть `запустить.bat`.

Нужна только Windows 10/11 и Chrome или Edge. Python не требуется:
локальный сервер поднимает встроенный PowerShell (`serve.ps1`).

**Преимущества:** ИИ работает офлайн через WebGPU, полностью бесплатно, стабильно и быстро.

### 2. Онлайн (GitHub Pages)

Страница публикуется автоматически: `index.html` в корне — это и есть сайт.
Открывать по адресу вида `https://<хозяин>.github.io/<репозиторий>/`.

**Ограничения:** На GitHub Pages ИИ работает через бесплатные API, которые могут быть медленными или временно недоступны.

## Почему нужен http://, а не двойной клик по index.html

`chat-widget.js` подключается как ES-модуль, а браузер запрещает модули и
кэш модели по протоколу `file://`. Отсюда и сервер, и GitHub Pages.

## Если `.bat` не запускается

Windows помечает скачанные файлы как чужие и может блокировать запуск.
Решение — PowerShell в папке сайта:

```powershell
Get-ChildItem -Recurse | Unblock-File
```

Либо запускать сервер напрямую:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```
