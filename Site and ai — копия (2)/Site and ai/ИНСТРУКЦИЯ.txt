КАК ЗАПУСТИТЬ САЙТ НА ДРУГОМ КОМПЬЮТЕРЕ
========================================

ВАЖНО: Python больше НЕ НУЖЕН. Сервер встроен в Windows.

1. ЧТО СКОПИРОВАТЬ
   Скопируйте всю папку "Site and ai" (флешка, облако, архив).
   Внутри должны быть файлы:
   - index.html
   - chat-widget.js
   - serve.ps1
   - запустить.bat
   - ИНСТРУКЦИЯ.txt

2. ЧТО НУЖНО НА ТОМ ПК
   - Windows 10 или Windows 11 (PowerShell в них уже есть)
   - браузер Chrome или Edge (для ИИ-чата)
   - интернет только на первый запуск ИИ-чата (качается модель)

3. ЗАПУСК
   Откройте папку и дважды щёлкните файл:
   запустить.bat

   Откроется чёрное окно сервера и вкладка браузера
   по адресу http://127.0.0.1:5500

   Это окно нельзя закрывать, пока вы на сайте.
   Чтобы выключить сайт — закройте чёрное окно.

4. ЕСЛИ WINDOWS БЛОКИРУЕТ ЗАПУСК СКРИПТА
   Windows может считать скачанный файл чужим и не пускать serve.ps1.
   Решение: правый клик по "запустить.bat" → Свойства →
   поставить галочку "Разблокировать" (Unblock) → Применить.
   После этого запускайте как в пункте 3.

   То же самое, если в чёрном окне появляется текст про
   "выполнение сценариев отключено" (ExecutionPolicy):
   правый клик по "запустить.bat" → Свойства → "Разблокировать".

5. ЕСЛИ САЙТ НЕ ОТКРЫЛСЯ
   - Не открывайте index.html двойным кликом — ИИ-чат так не работает,
     нужен именно запустить.bat.
   - В чёрном окне написано, какой адрес занял сервер.
     Если порт 5500 уже занят, сервер сам возьмёт следующий
     (5501, 5502 и т.д.) и напишет верный адрес — скопируйте его
     в адресную строку браузера.
   - Закройте все прежние чёрные окна с сервером и запустите заново.
   - Проверьте, что в браузере Chrome или Edge, а не Internet Explorer
     или базовый "Просмотрщик Windows".

6. ЗАПУСК КОМАНДОЙ (если не хотите через .bat)
   1) Откройте папку сайта.
   2) В адресной строке проводника введите powershell и нажмите Enter
      (откроется PowerShell уже в этой папке).
   3) Выполните:

      powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1

   4) В браузере откройте адрес, который напишет сервер
      (по умолчанию http://127.0.0.1:5500).

   Окно PowerShell не закрывайте, пока работаете с сайтом.
   Остановка: Ctrl+C, затем закройте окно.

7. ИИ-ЧАТ (кнопка справа внизу)
   - Работает в Chrome / Edge (нужен WebGPU).
   - Читает текст этой методички и отвечает по её разделам:
     ищет нужный раздел, цитирует промпты и чек-листы,
     даёт наводящие вопросы и ссылку-кнопку на раздел.
   - Если вопроса в методичке нет — честно об этом говорит,
     а не выдумывает ответ.
   - Модели подбираются автоматически: сначала Qwen 2.5 7B,
     если не хватит памяти — 3B, затем 1.5B и т.д.
   - Модель можно выбрать вручную в выпадающем списке вверху
     чата (кнопка «Сменить»). Удачная модель запоминается.
   - Первый запуск качает модель, нужен интернет. Дальше чат
     работает офлайн (модель уже в памяти браузера).
   - История диалога сохраняется между запусками; кнопка со
     стрелкой назад в шапке очищает диалог.
   - Пока ИИ отвечает, кнопка отправки превращается в «стоп» —
     генерацию можно прервать.
   - У каждого промпта в методичке есть кнопка «Спросить ИИ»:
     она открывает чат и вставляет промпт прямо в поле ввода.
   - Если чат пишет, что нет WebGPU — обновите браузер или
     включите аппаратное ускорение в настройках.
   - Адрес в браузере должен быть из окна сервера
     (http://127.0.0.1:5500), а не «файл:///...index.html».


КРАТКО
------
Скопировали папку → дважды по запустить.bat → открылся
http://127.0.0.1:5500 → кнопка ИИ справа внизу.
Никакого Python ставить не нужно.
